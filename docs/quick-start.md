# 快速使用指南

[返回 README](https://github.com/baofeidyz/139pan-tmdb-rename/blob/main/README.md) · [English README](https://github.com/baofeidyz/139pan-tmdb-rename/blob/main/README.en.md) · [快速开发手册](https://github.com/baofeidyz/139pan-tmdb-rename/blob/main/docs/development.md)

## 使用前准备

- 已登录的[中国移动云盘网页版](https://yun.139.com/w/)
- Chrome、Edge 或 Firefox 等现代浏览器
- [Tampermonkey](https://www.tampermonkey.net/)
- 从 [TMDB API 设置页](https://www.themoviedb.org/settings/api)获取的 Read Access Token
- Node.js 20 或更高版本（用于生成用户脚本）

Read Access Token 通常是较长的 JWT 字符串。不要把它提交到 Git、Issue、截图或聊天记录中。

## 安装

```bash
git clone https://github.com/baofeidyz/139pan-tmdb-rename.git
cd 139pan-tmdb-rename
npm run build
```

构建成功后：

1. 打开 Tampermonkey 管理面板，选择“添加新脚本”。
2. 删除编辑器中的示例内容。
3. 粘贴 `dist/139pan-tmdb-renamer.user.js` 的完整内容。
4. 保存，并确认脚本已启用。
5. 打开或刷新 `https://yun.139.com/w/`。

升级时重新拉取源码、执行 `npm run build`，再用新的构建产物覆盖 Tampermonkey 中的脚本。

## 推荐目录结构

```text
剧集名称/
├── S00/
│   └── 特别篇.mkv
├── S01/
│   ├── 第01集.mkv
│   └── 第02集.mkv
└── S02/
```

- 当前季度目录名必须包含 `S` 加 1–3 位数字，例如 `S01`、`S2` 或 `S100`。
- 脚本把季度目录的上一级目录作为默认剧名。
- 若当前选中了一个文件夹，搜索时会优先采用该文件夹名称。
- 视频的原扩展名和可识别的版本标签会保留。

## 标准操作流程

### 1. 捕获当前目录

登录移动云盘，进入具体的 `Sxx` 目录。若面板显示“移动云盘授权：等待页面请求”，刷新页面或切换到其他目录再返回，让网页重新请求文件列表。

授权上下文只存在当前页面内存中，不会写入用户脚本存储。刷新页面后需要重新捕获属于正常现象。

### 2. 配置 TMDB

打开“TMDB 重命名”面板，粘贴 TMDB Read Access Token，点击“保存 Token”。Token 会保存在 Tampermonkey 的隔离存储中，而不是移动云盘页面的本地存储。

### 3. 确认剧集

点击“按剧名搜索”，通过剧名、原名、年份和地区确认正确结果，再点击“确认选择并加载”。脚本会读取当前目录并载入当前季度与 `S00` 特别篇数据。

### 4. 审核计划

逐项检查原名称、TMDB 集数、目标名称、置信度和警告。低置信度或未匹配项目应人工选择正确剧集。

“全选可改名项”只会选择已匹配、目标名称有效且名称确实发生变化的文件。未匹配文件不会被自动选中。

### 5. 执行并验证

点击执行后，浏览器会再次显示待处理数量。确认后脚本会：

1. 重新读取目录，阻止对已变化或已删除文件的操作。
2. 必要时使用临时文件名解决同批次名称交换冲突。
3. 以有限并发提交重命名请求。
4. 重新读取目录并校验每个最终名称。

成功项目会生成当前会话的恢复计划。恢复同样需要确认，并会在完成后校验结果。

## 命名模式

| 模式 | 示例 |
| --- | --- |
| 完整 | `剧名.S01E02.标题.1080p.mkv` |
| 紧凑 | `剧名.S01E02.1080p.mkv` |

目标名称由实际 TMDB 数据和解析出的版本标签决定，表格中的预览结果是执行前的最终依据。

## 常见问题

### 一直等待移动云盘授权

确认脚本已启用且网址以 `https://yun.139.com/w/` 开头，然后刷新文件列表或重新进入当前目录。若网站升级后仍无法捕获，请提交脱敏后的复现步骤。

### 无法识别季度

把当前目录改为包含 `Sxx` 的名称，例如 `S01`。脚本不会从 URL 猜测季度。

### TMDB 搜索不到或结果不正确

确认上一级剧名目录或当前选中的文件夹名称足够准确。可以临时调整目录名称后重新搜索；必须明确选择正确候选项才会生成计划。

### 计划存在阻断错误

检查重复目标名称、已存在文件和未完成的人工匹配。只有计划通过校验且至少勾选一个有效项目时，执行按钮才可用。

### 授权失效或批次中止

刷新网页以获得新的授权上下文，重新扫描并审核计划。不要直接重复执行旧计划，因为云端目录状态可能已经变化。

## 安全提醒

- 首次使用只在少量、可恢复的测试文件上验证。
- 不要关闭预览直接批量处理重要资料。
- 不要分享包含 Token、请求头、Cookie、文件 ID 或账号信息的日志。
- 中国移动云盘网页内部接口可能调整；接口现状见[已脱敏 API 契约](https://github.com/baofeidyz/139pan-tmdb-rename/blob/main/docs/139pan-api-contract.md)。
